# 🌤️ Meteo App

Une application météo simple et rapide développée avec **React JS** et **Vite**, utilisant une API météo pour afficher les conditions en temps réel.

---
## 🚀 Fonctionnalités

- 🔍 Recherche de ville
- 🌡️ Affichage de la température actuelle
- 🌥️ Affichage de l’état du ciel (soleil, pluie, nuage, etc.)
- 📍 Données météo en temps réel via API
- ⚡ Interface rapide grâce à Vite

---
## 🛠️ Technologies utilisées

- React JS
- Vite
- JavaScript (ES6+)
- API météo (OpenWeatherMap ou autre)
- CSS
